HackLife Quiz App

An Android quiz app that challenges users to identify whether popular life tips are **Hacks** or **Myths**. Built with Kotlin and Android Studio.


Features

 True/False style quiz on real-world life hacks and myths
 Instant feedback with explanations after each answer
 Final score screen at the end of the quiz
 Full answer review screen to recap all correct answers



Project Structure



`MainActivity.kt` App entry point with a start button 
`QuizActivity.kt`  Core quiz logic, answer checking and scoring 
`ScoreActivity.kt`  Displays the user's final score 
`ReviewActivity.kt`  Shows all questions with their correct answers 



Getting Started

Prerequisites
- Android Studio Hedgehog or later
- Kotlin 1.9+
- Minimum SDK: API 24 (Android 7.0)

Installation
1. Clone the repository
```bash
   git clone https://github.com/your-username/hacklife-app.git

2. Open the project in Android Studio
3. Let Gradle sync complete
4. Run on an emulator or physical device
